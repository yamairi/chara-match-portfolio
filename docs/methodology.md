# 方法論

## 標準化・次元圧縮・クラスタ

人工的な連続価値観項目を加重平均と加重標準偏差で標準化し、
加重相関行列の固有分解で主成分を抽出します。負荷量をVarimax回転し、
同じ回転を主成分得点へ適用して再標準化します。
これは回転PCAによる要約であり、潜在変数の因果的意味を推定するものではありません。
最大絶対負荷量の符号を正にそろえますが、意味付けや固定的な順序保証はありません。
重み付きK-means++を複数初期値で実行し、加重クラスタ内平方和が最小の解を選びます。

## 商品モデルと検証

購入量が正なら購入ありとし、背景カテゴリのみのBasicモデルと、
背景カテゴリ＋価値観成分のExtendedモデルをL2ロジスティック回帰で比較します。
切片は正則化せず、学習時の重みは平均1に正規化します。
層化交差検証で加重Log Lossを比較し、改善した場合にExtendedを選びます。
各foldの標準化・PCA・回転は学習部分だけで学習します。
カテゴリ集合は説明変数から事前に作る固定のone-hot表現です。
foldのLog Lossは検証重み合計で加重して統合します。

これはモデル選択用CVであり、選択後の性能を独立に評価するテストセットではありません。
最終モデルは全人工データで学習し、同じデータのクラスタ内平均予測を `Fit`、
実購入率を `Actual` として `Gap = Fit × (1 − Actual)` を計算します。
Gapは記述的な候補探索指標です。

## 支持者ベクトルの縮約

購入者・支持者のクラスタ別加重構成比を作ります。
支持者の実効数 `n_eff = (Σw)² / Σw²` を用い、
`r = n_eff / (n_eff + m)`、`C* = r C + (1 − r) Market` と縮約します。
複数のmを出力しますが、ペアの標準評価はm=30を使用します。
信頼度区分は実効数の便宜的な区分で、統計的な信頼区間ではありません。

## ペアスコア

- Compatibility = cosine(購入者構成比, C*)
- Affinity = C* / Market
- Expansion = Σクラスタ Gap × max(Affinity − 1, 0) × r
- Customer Shift = C* − 購入者構成比

Unexpected Affinityでは、架空の背景カテゴリから支持確率を推定し、購入者内で
加重実支持率と加重期待支持率との差を計算します。同一標本内の記述的残差です。

CompatibilityとExpansionの上位四分位を基準として4種類の候補へ分類します。
候補群を変えると分位点も変わるため、分類は絶対評価ではありません。

## 適用範囲

数値項目に欠損・無限大がある場合、重みが非正の場合、商品にCVに必要な両クラスがない場合、
支持が二値でない場合などは明示的に停止します。自動補完は行いません。
クラスタが空になる退化データも停止します。
不確実性の区間推定、外部データ検証、因果効果推定は実装範囲外です。
