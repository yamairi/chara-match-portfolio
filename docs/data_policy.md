# データ方針

**元データ非公開・ポートフォリオ用の一般化再実装。**

同梱CSVは `src/chara_match/synthetic.py` の乱数生成だけから作られます。
この生成器は外部ファイル、ネットワーク、元データの統計量、学習済みモデルを読みません。
連番ID、価値観変数、架空カテゴリ、購入量、支持、重みを新しく生成します。
分析しやすい人工相関は設けていますが、実際の分布を推定・複製したものではありません。

元の個票、調査票、集計結果、実体名、調査固有コード、意味付き項目対応表は同梱しません。
出力にある件数や割合は、この人工データについて計算した数値です。

`sample_data/` と `outputs_sample/` は対になる人工データとその結果です。
元データや秘密情報をこれらのフォルダに追加しないでください。
